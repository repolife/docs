## June 9, 2026

### Added

- Added an immersive **book reading mode** to the Bible reader. Tap the book icon in the reader header for a distraction-free, full-screen view with flowing, book-style typography on a warm parchment background. Move between chapters with the in-view **Previous** and **Next** links, and tap **✕** to return to the standard reader.

### Improved

- Improved book mode so your place carries over when switching between the standard reader and book mode, bookmarked verses keep their highlight color, and passage text is easy to select for copying.
- Improved desktop book mode to fill the screen, hide the side navigation and study panel, and center the passage in a comfortable reading column.

### Fixed

- Fixed Bible verse bookmark highlights that could stay hidden in the web app until you changed chapters, so they now appear once bookmarks finish syncing.

## June 8, 2026

### Improved

- Improved tablet and desktop Bible study with a split verse panel for cross-references. Related verses can open in the reader column while the cross-reference panel stays available, with a **Back to original verse** action for returning to the starting passage.
- Kept the phone cross-reference flow focused on the existing **View all Cross-References** screen, so smaller screens still use the full-list experience with filtering, bookmarking, and study actions.

## June 6, 2026

### Added

- Added copy range actions in the Bible reader. You can choose a start and end verse, preview the selected passage, and copy the formatted text for messages, emails, or notes.

## June 2, 2026

### Added

- Added bookmark sync across devices, so saved Bible verse bookmarks can upload from one signed-in app and restore on another after the latest app update.
- Added PDF downloads for public studies, so you can save or share a formatted copy from the public study detail page.

### Improved

- Improved **Saved Verse Images** readability with selectable text color modes, stronger text shadows, and a clearer reference label on busy backgrounds.
- Improved cross-reference lists by showing the source verse text above related verses, so you can keep the original passage in view while reviewing references.
- Improved the Bible passage picker with stable **Old Testament** and **New Testament** quick-jump buttons that update as you scroll without snapping the book list on open.

## June 1, 2026

### Added

- Added desktop Bible reader shortcuts: use **Left** and **Right** to move between chapters, **Up** and **Down** to scroll, **G** to open the passage picker, and **/** to open Bible Search.
- Added Sign in with Apple support for the web and desktop app, using the browser-based Apple OAuth flow.

### Improved

- Improved the Bible passage picker with stacked **Old Testament** and **New Testament** sections and quick-jump buttons that disable when a search has no matches in that testament.
- Improved Saved Verse Images by caching template backgrounds locally after first load and using a mobile-friendly bottom-sheet font picker.
- Improved desktop auth so **Continue without account** and auth warnings use visible browser prompts.
- Improved the desktop translation picker so the modal stays centered and no longer stretches too wide on large screens.

### Fixed

- Fixed a Saved Verse Images loading state so the spinner appears while image templates load.
