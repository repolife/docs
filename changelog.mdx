## May 26, 2026

### Added

- Added **Saved Verse Images**. You can create scripture art from the verse study panel, choose a curated background, pick a font, and save or share the generated image.
- Added a **Verse images** collection under **Studies → Saved** for viewing, editing, sharing, and deleting saved verse images.

### Improved

- Improved Saved collections so the built-in **Verse images** collection is handled as a system collection.
- Improved Chapter Guide answers with more educational context for speakers, people, places, and settings.
- Improved Spanish study support for letter breakdowns, lexical meaning, and historical-context generation.

### Fixed

- Fixed duplicate Strong's badge rendering for repeated Strong's numbers.
- Fixed verse image reference fallbacks and kept the verse text free from added punctuation.
- Fixed Spanish historical-context generation for Spanish references such as `Juan 2:1`.

## May 22–25, 2026

### Added

- Added a premium **Chapter Guide** at the end of Bible chapters. You can ask scoped questions about the current chapter, use suggested prompts, and start an AI study when a question needs deeper exploration.
- Added end-of-chapter actions to bookmark the whole chapter or create a study from the chapter.
- Added a full-screen Bible jump picker with safer book, chapter, and verse validation.
- Added cross-reference actions so you can bookmark related verses or start manual and AI studies from selected cross-references.
- Added saved-verse study creation from the **Bible verses** collection.

### Improved

- Improved AI safety guardrails for study generation, chapter guides, and synced notes before publication.
- Improved offline database refresh fallback behavior.
- Improved Bible search replay after query changes and failures.
- Improved saved bookmark parsing and migration hardening for verse and chapter bookmarks.
- Improved Spanish chapter guide answers and localized Bible jump picker controls.

### Fixed

- Fixed cross-reference bookmark selection edge cases, including preserving selections after errors.
- Fixed stale verse values in the Bible jump picker and safe-area spacing on modern devices.
- Fixed chapter guide request handling and removed an obsolete chapter-guide search action.
- Fixed saved chapter bookmark navigation and restored saved verse edit affordances.

## May 7–21, 2026

### Added

- Added same-book passage ranges for manual reading-plan days. You can add a range such as `Genesis 1:1–3:7`, and Seed Scroll expands it into the needed per-chapter readings.
- Added optional notification preferences so you can choose which community and reading-plan alerts you receive.
- Added private study link sharing with token-protected access for people who have the link.
- Added reading-plan verse highlighting in the Bible reader, including colored verse numbers and a side rail for assigned verses.
- Added search result actions for saving verses as bookmarks or starting a study from a result.
- Added photo import for bookmarks, including review tools, manual verse fallback, and improved multi-verse detection.
- Added more bookmark organization tools, including color indicators, saved verse editing, editable hashtag names, and hashtag filters.
- Added direct Bible and study links, reader text pinch resizing, Bible reader walkthrough replay, historical-context indicators, and audio playlist actions.

### Improved

- Improved reading-plan imports from PDFs, documents, webpages, long annual schedules, and background generation jobs.
- Improved saved and bookmark collection screens with clearer collection language, denser collection pills, and more stable refresh behavior.
- Improved historical-context coverage and availability indicators from the checked source corpus.
- Improved WEB Strong's alignment and Spanish AI study verse translation behavior.
- Improved release automation for the app repository with generated changelogs and Conventional Commit PR checks.

### Fixed

- Fixed private study link edge cases and reduced shared-link token exposure risk.
- Fixed bookmark cursor stability, hashtag rename errors, imported bookmark previews, and bookmark removal state.
- Fixed photo-import JSON parsing failures, timeout behavior, and malformed list handling.
- Fixed reading-plan save cleanup, generation polling errors, file import failures, and completion animation test loops.
- Fixed Bible reader note indicators, quick-note indicators, red-letter highlighting alignment, translation-change scrolling, and historical-context empty states.
- Fixed study republish notifications, direct share failure copy, study note PDF formatting, and PDF author branding.
