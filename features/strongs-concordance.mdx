Every word in Seed Scroll's native Strong's translations is linked to a Strong's number — a unique identifier for each Hebrew or Greek root word in the original scriptures. You can access the Strong's definition without leaving the reader.

KJV+, RV1909, and BSB include native Strong's tagging. WEB uses KJV-backed verse-level Strong's study so readers can still explore the original-language context without claiming exact WEB word-level tagging.

<Note>
  Strong's Concordance is a free feature. You do not need a premium subscription to use it.
</Note>

## How to open a Strong's definition

<Steps>
  <Step title="Long-press a verse">
    Press and hold any verse in the reader. Small badge dots appear on each word in the verse.
  </Step>
  <Step title="Tap a badge">
    Tap any badge to open the Strong's definition panel for that word.
  </Step>
  <Step title="Read the entry">
    The panel shows the original word, transliteration, pronunciation, part of speech, and a full definition.
  </Step>
</Steps>

## What the definition panel shows

| Field | Description |
|-------|-------------|
| **Original word** | The Hebrew or Greek word in its original script |
| **Transliteration** | A phonetic spelling using Latin letters (e.g., *agapē*) |
| **Pronunciation** | A guide to how the word is spoken |
| **Part of speech** | Noun, verb, adjective, preposition, etc. |
| **Definition** | The full Strong's dictionary entry for the word |
| **Root word** | The root or parent entry the word is derived from, if applicable |

<Note>
  Hebrew entries are numbered with a leading **H** (e.g., H7225). Greek entries use a leading **G** (e.g., G3588). These numbers match the Strong's numbers used in printed concordances.
</Note>

## See every verse that uses the same word

At the bottom of the definition panel, tap **See all verses** to open a full list of every verse in the Bible where that exact Strong's number appears.

On that screen you can:

- **Filter by book** — tap the book name dropdown to narrow results to a single Bible book
- **Tap any verse** — jump directly to that verse in the reader, with the matching word highlighted

This makes it easy to trace how a single Hebrew or Greek word is used throughout all of scripture.

## Strong's number counts

While the definition panel is open, the panel displays how many times the word occurs in scripture. Use this to quickly gauge whether a word is rare or common before exploring the full verse list.
