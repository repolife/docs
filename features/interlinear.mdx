The interlinear view displays the original language text of each verse directly above the English words, aligned side by side. This lets you see exactly which Hebrew or Greek word corresponds to each word in the KJV+ translation without needing to know either language.

- **Old Testament** — Hebrew text (reads right to left)
- **New Testament** — Greek text (reads left to right)

## How to enable the interlinear view

<Steps>
  <Step title="Long-press a verse">
    Press and hold any verse to open the verse study panel.
  </Step>
  <Step title="Tap the Interlinear tab">
    In the panel, tap the **Interlinear** tab (the languages icon). The original language text for that verse loads below the English.
  </Step>
  <Step title="Tap any original-language word">
    Tap any word in the interlinear strip to open its Strong's definition, transliteration, and morphology tag.
  </Step>
</Steps>

## First-time download

The interlinear database is not included in the initial app download. The first time you open the interlinear tab, Seed Scroll downloads the database in the background (~46 MB). A progress indicator appears while the download is in progress.

<Note>
  After the first download, the interlinear works fully offline. You only need a network connection for the initial download.
</Note>

<Warning>
  Open the interlinear tab on Wi-Fi the first time to avoid using mobile data.
</Warning>

## What each word shows

For every word in the interlinear strip, Seed Scroll displays:

| Field | Description |
|-------|-------------|
| **Original text** | The Hebrew or Greek word in its native script |
| **Transliteration** | A Latin-alphabet phonetic spelling of the word |
| **English gloss** | A short English meaning for that specific word form |
| **Strong's number** | The concordance number linking to the full definition |
| **Grammar tag** | A morphology code showing tense, case, number, gender, etc. |

## Proto-Sinaitic letter meanings (Hebrew)

For Hebrew words, Seed Scroll includes an optional layer that shows the pictographic meaning of each letter based on Proto-Sinaitic — the ancient ancestor of the Hebrew alphabet. Each Hebrew letter originated as a picture (for example, **aleph** = ox, **bet** = house), and seeing those roots can give additional insight into the meaning embedded in a word.

Tap the **Hebrew Letters** section within the interlinear panel to expand the pictographic breakdown for any Hebrew word.
